**Запуск и тестирование frontend на Angular**  
  
Предусловия:  
Произведен запуск Spring-backend.  
Установлены компоненты Node.js npm.  
  
1. Запустить 1 install.bat для настройки Angular-приложения и его компонентов.  
2. Запустить 2 start.bat для инициализации frontend (в консоли отобразится адрес localhost, где можно провести ручное тестирование приложения в браузере).  
3. Запустить 3 test.bat для автотестирования на Karma (Jasmine) с последующим выводом отчета о тестировании.  
4. Запустить 4 e2e.bat для проведения End-2-End теста на Cypress (при интерактивном тесте изменить в bat-файле e2e на e2e:open).
