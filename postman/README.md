**Инструкция по использованию**  
  
**Коллекция запросов**  
  
**Математические операции**  
  
**Addition (Сложение)**  
Метод: POST  
Endpoint: `/compute`  
Параметры: a=10, aBase=10, b=5, bBase=10, op=ADD  
Ожидаемый результат: 15  
  
**Subtraction (Вычитание)**  
Метод: POST  
Endpoint**: `/compute`  
Параметры: a=10, aBase=10, b=5, bBase=10, op=SUBTRACT  
Ожидаемый результат: 5  
  
**Multiplication (Умножение)**  
Метод: POST  
Endpoint: `/compute`  
Параметры: a=10, aBase=10, b=5, bBase=10, op=MULTIPLY  
Ожидаемый результат: 50  
  
**Division (Деление)**  
- **Метод**: POST  
- **Endpoint**: `/compute`  
- **Параметры**: a=10, aBase=10, b=5, bBase=10, op=DIVIDE  
- **Ожидаемый результат**: 2  
  
**Получение истории вычислений**  
  
**Get Calculations History**  
Метод: GET  
Endpoint: `/`  
Параметры: from=2024-01-01T00:00:00, to=2024-12-31T23:59:59  
Описание: Получение всех вычислений за определенный период времени  
  
**Нагрузочное тестирование**  
  
**Load Test - Sequential 1000 iterations**  
Описание: Последовательная отправка 1000 запросов  
Использует: Случайные числа для параметров a и b  
Собирает статистику: Среднее, максимальное и минимальное время ответа  
  
**Load Test - Parallel 1000 iterations**  
Описание: Параллельная отправка 1000 запросов  
Использует: Случайные числа для параметров a и b  
Собирает статистику: Среднее, максимальное и минимальное время ответа  
  
**Pre-request Script**  
  
Коллекция содержит pre-request script, который:  
1. Получает переменные из выбранного environment (protocol, host, port, apiPath)  
2. Формирует полный URL для API  
3. Устанавливает переменную `fullApiUrl` для использования во всех запросах  
4. Логирует сформированный URL в консоль  
  
**Основная инструкция**  
1. Открыть Postman  
2. Нажать "Import"  
3. Выбрать файл `CalcAPICollection.json`  
4. Импортировать environments `local-environment.json` и `dev-environment.json`  
5. Выберать нужный environment (Local или Dev)  
6. Пройти по коллекции согласно ТЗ  
7. Для параллельного запуска Load Test - Parallel 1000 iterations необходимо запустить тест дважды для одновременного выполнения
